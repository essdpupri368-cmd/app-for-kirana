# Billing App – APK बनाने के चरण
1. github.com पर free account -> New repository.
2. इस फ़ोल्डर की सारी files (".github" फ़ोल्डर सहित) upload करें.
3. Actions tab -> "Build APK" -> Run workflow (~8 min).
4. Run में Artifacts -> billing-apk डाउनलोड करें, zip खोलें, app-release.apk install करें.
दुकान का नाम: lib/main.dart में `shopName` बदलें.
